# 🎨 Intern Documentation Style Guide

*Formatting suggestion for contributions to the Intern Playbook.*

---

## Why Format?
Formatting to a specific style will help with consistency, readability, and longevity of the TechSquare Intern Playbook.

### Heading
```markdown
# Title

*short subtitle*

--- (horizontal rule)

## Subheadings
```
- Start your document with an H1 heading for the title.
- Follow the title heading with a with a brief statement or description of the topic, explaining what the resource page is about.
- Be sure to split the heading from the rest of the document by using markdown's `---` horizontal rule.

### Lists
When explaing something in sequence, such as a process of installation, use ordered lists.
```markdown
1. Install tool
2. Edit config file
3. Start the service
```
When listing information that does not have a particular order, use unordered lists.
```markdown
Different Linux Distros
- Rocky
- Fedora
- Ubuntu
```

### Links
Embed links you used to gain further understanding of a subject, or when you find helpful resources to share. The syntax for embedded links is `[Text](Link)`.

### Resources
Be sure to include a list of resources at the bottom of your document for easy accessibility.

### Contributing
Be sure to read this github repository's [README](https://github.com/TechSquareInc/intern-playbook/blob/main/README.md) for instructions on setting up a development environment for contributing to the Intern Playbook. The playbook is written in a combination of **restructured text** and **markdown** formats. You'll find the only page written using restructured text is the index page (`index.rst`). To keep up with consistency, it is reccommended to use markdown for all other resource pages.

> **Note:** In the upper right hand corner of each resource page, next to the "Contents" hamburger menu, there is a "View this page" feature that shows the markdown version of each resource page. If you're unsure of the best way to emmulate the playbook's style, you can use this feature as a reference.

# 🤺 BashBlaze: 7 Days of Bash Scripting

*Undertake a journey to become experts in Bash scripting -- in just 7 days!*

---

## Getting Started

This is a week long challenge designed to introduce the fundamentals of Bash scripting and sharpen your skills.

**To get started:**

1. Fork this [repository](https://github.com/prajwalpd7/BashBlaze-7-Days-of-Bash-Scripting-Challenge) to create a copy of the repo in your own space.
2. Clone the forked repo to your local machine. This is where you'll work on your daily challenge scripts. 
3. Once you complete a challenge script, commit and push your changes to your forked repository to see your progress on Github.

> **Note:** This challenge will require you to have some familiarity using Git. To freshen up or sharpen your Git skills, visit the local intern learning resource for [Git](../fundamentals/getting-started-with-git).
